This is the mechanism behind the comparison. The skill was made robust first, so that it is no longer the bottleneck; after that, task success tracks grounding accuracy closely along the line accuracy × 96.2%. Qwen-32B sits slightly above the line on dev, which is where its dev result was optimistic (test: 91.0). The practical consequence: a new VLM can be evaluated cheaply offline on cached scenes, and its effect on task success predicted before running the robot.
