MimicGen (MuJoCo 2.3.2) · 5 contact-rich tasks, 1000 demos each · train on D0, test on D0 / D1 / D2 (official wider placements)

Segments come from replaying every demo's recorded states. Each contact phase starts at the first physical contact between the gripper, or the held object, and MimicGen's reference object for that subtask; the learned part starts 10 steps earlier. Segments are 42% of Square's frames. A segmenter using only DROID-style signals finds grasps reliably but insertions poorly, so the DROID tier will need a better contact detector.
