Where the loss comes from: now almost only the VLM

How it is measured

Swap one part for a perfect one on the same 505 tasks: GT grounding (VLM), then a scripted grasp (policy).

Grasp policy: 16 → 2

Per episode, the robust skill caused 0 of v7's 55 failures. v5's caused most.

Noise floor ≈ 2–4%

Repeated runs: right-object failures move between tasks (1–6% per category); wrong-object ones repeat.

LIBERO-Plus dev split · VLM loss = (skill + GT grounding) − system · grasp loss = (GT + scripted grasp) − (skill + GT) · rest = 100 − (GT + scripted)

Two complementary views agree. Controlled swaps replace one component at a time with a perfect version on the same tasks. Per-episode blame reads each failed episode: wrong object chosen or basket off by more than 5 cm is the VLM; correct positions but nothing or a neighbour grasped is the grasp policy; correct positions and the right object carried is transport, release or run-to-run noise. We checked the last bucket with repeats on the 80 camera tasks: v7 right-object failures were 11, 2 and 1 in three runs, ground truth 2 and 5, on different tasks each time, while wrong-object failures were exactly 6 every run. So single-run category numbers carry about ±5 points of noise, and the wrong-object picks are systematic VLM errors.
