Value and novelty

Closest prior work, HITL-TAMP (CoRL 2023) and SkillMimicGen (2024), already learns only contact-rich segments, with TAMP and motion planning in between. Both need object models and poses, and report mainly in-distribution success.

Open-world grounding

A local VLM from RGB-D and language replaces known object models.

Generalization, measured

Standard shift axes: MimicGen D0→D2, LIBERO-Plus / PRO, PolaRiS.

Pretrained VLAs, real data

Segment-only vs whole-trajectory fine-tuning, small to large, on DROID.

Why it works

The C1 control and egocentric inputs separate “start close” from “learn less”.
