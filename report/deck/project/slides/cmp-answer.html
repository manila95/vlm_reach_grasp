The answer

Yes. With a stronger VLM and no new robot data, the modular system beats π0.5 by 4.7 points.

What it shows

Perception and control can improve separately. A VLM upgrade is a drop-in gain, measurable offline.

The caveats

Our grounder is larger than π0.5 and uses depth; the best one is an API model. Local Qwen-32B ties π0.5.

Next

A local grounder at Gemini's level (cascades, multi-view votes); a VLA as fallback skill; the real Franka.

LIBERO-Plus test split: ours + Gemini 3.8 Flash 94.0% [92.9–94.9] vs π0.5 89.3% [87.8–90.5], paired McNemar p = 5·10⁻⁸

The comparison is not between equal model sizes: the VLAs are end-to-end policies pretrained on large robot datasets and fine-tuned on LIBERO; our system uses a much smaller robot-trained component (a 78 M-parameter diffusion skill trained on 50 demos per task, only on the grasp segment) and an off-the-shelf VLM with RGB-D, which can be swapped. The honest claim is about the route: improving the perception module, without touching robot data, took the system from a tie with π0.5 to a significant win. For a fully local deployment on the Franka, today's best open model gives parity, so closing the gap between Qwen-32B and Gemini is the next engineering target.
