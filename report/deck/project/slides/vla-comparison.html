The modular system's errors are attributable: we can say which part failed and fix it in isolation. Upgrading the VLM alone took the test split from 88 to 94%, with the same 50-demo skill, significantly above π0.5.

Numbers: LIBERO-Plus test split (2,013 tasks) · VLA checkpoints evaluated as released

The comparison is not about who has the bigger model. The VLAs learn perception, language and control together from large robot datasets; their failures under start-pose changes show that motion generalisation is the hard part for them. Our system learns only the local contact skill from 50 demos and plans the rest, so start-pose changes cost nothing, and its perception is an off-the-shelf VLM that can be replaced. The price is that every perception error passes straight through: our language and camera losses are grounding mistakes, which the next VLM generation already fixes. On the real Franka, the same split lets us use a local model; today the best local grounder (Qwen-32B, 91%) is on par with π0.5, and the API model (Gemini Flash, 94%) is clearly above it.
