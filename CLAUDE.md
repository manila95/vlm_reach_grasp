# CLAUDE.md — project context for Claude Code

PoC: a VLM grounds the target, a scripted controller reaches a handoff pose, and a small diffusion policy does only the grasp-and-lift.
Benchmark: LIBERO-Object. Write-up: `report/VLM_Reach_LocalGrasp_Report.ipynb` (generated by `report/build_report.py`). See `README.md` for results and `docs/DEVLOG.md` for the history of decisions.

## Environment
- Always `source env.sh` first. It sets `MUJOCO_GL=egl` and `__EGL_VENDOR_LIBRARY_FILENAMES=/usr/share/glvnd/egl_vendor.d/10_nvidia.json`; without these, robosuite cannot create a headless context on this machine (Mesa is tried on /dev/dri and fails). It also sets `$PY` (conda env `vlmrg`, python 3.10).
- The exit-time `EGLError ... __del__` tracebacks are harmless.
- The VLA baseline runs in the separate `spatialforcing` env from `~/projects/Spatial-Forcing/openvla-SF` (see `vrg/vla_eval.py` docstring).
- The machine is shared with other users: keep GPU jobs reasonable and check `nvidia-smi` before launching many.

## Launching long jobs (budget first)
Before launching any batch of runs, write down each job's peak host RAM and GPU memory and check the total fits: 123 GB RAM, 2×96 GB GPUs, other users, and ≥24 GB of headroom. If it doesn't fit, queue the jobs rather than start them together. Then launch every job with `tools/launch_job.sh NAME PEAK_GB GPU GPU_GB LOG READY_REGEX -- cmd...`. It waits for room, runs the job in its own systemd unit `vrg-NAME` with `MemoryMax=PEAK_GB`, and returns only once the job is loaded, so data loads never overlap. Never use `nohup`/`setsid`/`&` for long jobs: they stay in the session's cgroup, and on 2026-10-10 one OOM kill there took down every job plus the Claude session. Long jobs must also be resumable (trainers save `<out>/state.pt`).

## Conventions
- Raw robosuite images are upside down (OpenGL convention). Policies train and run on raw 128 px obs; anything shown to the VLM or in videos is flipped `[::-1]`.
- Actions are LIBERO OSC_POSE deltas `[dx,dy,dz (×5 cm), drot axis-angle (×0.5 rad), gripper ±1]` at 20 Hz. Policies predict 16-step chunks and execute 8.
- Eval protocol: 10 tasks × `EVAL_EPS` (20 init states, `vrg/ground_episodes.py`). `CALIB_EPS` (0,10,…,40) are only for the grounding bias. `HOLDOUT_EPS` (25/task) were untouched until the final check. Don't tune on them.
- OOD = `--shuffle` (`pipeline.shuffle_layout`, seed `7919*tid+ep`). Strict zero-shot runs must pass `--calib data/grounding.pkl` (bias from standard scenes), not the shuffled grounding file.
- Every result lives in `runs/eval/<name>/results.json` (per episode: success, fail phase, moved object, target). The report reads only these, so add new runs there and reference them by name in `build_report.py`.
- Final method ("v5"): `--method hier_vlm --auto_retract --lock_ori auto --retries 2 --j4_thresh=-1.0` with `runs/local_ego_50/ckpt.pt` (egocentric skill: `--cams wrist --mask_xy`).

## Gotchas learned the hard way
- Policy observations must be rendered at 128 px (training resolution). Render video frames separately with `env.sim.render(...)`; rendering the env at 512 px silently broke the demos once.
- Don't wait on jobs with `pgrep -f "<pattern>"` loops whose own command line contains the pattern: one hung on itself.
- Diffusion sampling is unseeded, so 20-episode per-task differences are noise. Compare full-suite numbers with Wilson CIs.
- Isaac Lab (Franka track, `vrg/franka/`): source `/scratch/kaustubh/vlm_reach_grasp/isaac/env.sh`. Conda's activate.d sets `__EGL_VENDOR_LIBRARY_DIRS` to Mesa only, which breaks NVIDIA's Vulkan ICD ("No device could be created"); env.sh unsets it. Kit ignores SIGTERM and can hang on exit: use `os._exit` and `timeout -s KILL`.
- Don't split Qwen3-VL-32B over both GPUs with `device_map="auto"`: every generation came out NaN (`!!!!`). It fits on one GPU.
- Shuffled targets near the workspace edge drive the Panda's elbow (joint 4) to its limit if the policy tilts the wrist; v5's posture-aware roll/pitch lock exists for this. Locking yaw breaks the tomato-sauce grasp.
- `checkpoints (runs/*/ckpt.pt)` and `data/libero_object.npz` are not in git (size). Rebuild with the README commands.
